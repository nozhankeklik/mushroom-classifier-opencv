# Mushroom Species Classifier (OpenCV) 🍄

A foundational project exploring image processing pipelines and basic classification techniques using Python and OpenCV.

> **Note:** This repository serves as a practical study to understand the core concepts of computer vision, focusing on feature extraction and data preprocessing steps, based on established academic examples.

## 🎯 Project Goals
Instead of building complex deep learning models from scratch, the focus of this project was to understand the underlying mechanisms of image classification:
* Understanding how images are represented as matrices.
* Applying **OpenCV** for preprocessing (e.g., resizing, color space conversion).
* Exploring basic **feature extraction** methods to identify visual characteristics of mushroom species.

## 🛠 Tech Stack
* **Python**
* **OpenCV** (Computer Vision Library)
* **NumPy** (Numerical operations on image matrices)
* **Google Colab** (Development environment)
